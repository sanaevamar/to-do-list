# Список задач (To-Do List)

Небольшой сайт для списка дел. Задачи можно добавлять, отмечать выполненными и удалять. Они сохраняются в браузере и остаются после обновления страницы.

## Возможности

- **Добавление задачи.** Кнопка «Добавить» или клавиша Enter. Пустую задачу добавить нельзя: строка ввода коротко вздрагивает.
- **Отметка выполненных.** Чекбокс слева; кликнуть можно и по самому тексту. Выполненная задача становится серой и зачёркивается.
- **Удаление.** Кнопка с корзиной справа от задачи.
- **Сохранение.** Задачи хранятся в `localStorage` и остаются после обновления страницы. Если сайт открыт в двух вкладках, изменения в одной сразу видны в другой.

Дополнительно: счётчик и полоса прогресса, заглушка для пустого списка, вёрстка под телефон, управление с клавиатуры, учёт системной настройки «уменьшить движение».

## Как запустить

Сборка и сервер не нужны: достаточно открыть `index.html` в браузере.

## Стек

HTML, CSS и JavaScript без фреймворков и зависимостей. Шрифты Oswald и Manrope подключены из Google Fonts.

## Структура

```
index.html   — разметка страницы
style.css    — стили
script.js    — логика: добавление, отметка, удаление, сохранение
favicon.svg  — иконка вкладки
```
